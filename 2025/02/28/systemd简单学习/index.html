systemd简单学习

systemd是作为现代系统和服务管理器替代SystemV init，同时也兼容SystemV init。他是一套工具兼顾了系统启动时，比如磁盘挂载，网络配置，ntp时间同步等。系统启动时，会启动一个systemd的一号进程，用于管理用户态的进程和服务。

一些命令

Service Systemd 意义
service nginx start systemctl start nginx 启动
service nginx restart systemctl restart nginx 重启
service nginx stop systemctl stop nginx 暂停
chkconfig –list systemctl list-unit-files –all –state enabled 查看自启的服务
chkconfig nginx on systemctl enable nginx 开启自启动
chkconfig nginx off systemctl disable nginx 关闭自启动
service nginx reload systemctl reload nginx 重载配置文件
service nginx status systemctl status nginx
systemctl is-active nginx
systemctl is-failed nginx
systemctl is-enabled nginx		 查看服务状态
systemctl list-unit-files –all –type service 查看存在的服务
systemctl –failed 查看失败的服务
systemctl daemon-reload 重载systemd服务

创建服务

Systemd unit位置主要存在于两个地方

/usr/lib/systemd/system

存放所有systemd unit,包括service和其他类型

/etc/systemd/system

存放自启动文件

单元类型

https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/7/html/system_administrators_guide/chap-Managing_Services_with_systemd#sect-Managing_Services_with_systemd-Introduction

type suffix descrition
service .service 一个服务
target service .target 一组服务
automount .automount 在需要访问时挂载
mount .mount 开机自动挂载
socket .socket 套接字

编写服务

因为我需要一个Tomcat的自启动任务,所以是service类型

Type Simple 类型适用于 ExecStart执行后运行于前台的程序 直接在当前终端运行 例如: promethus
